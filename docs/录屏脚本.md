# 录屏脚本（目标时长 2 分 45 秒）

> 赛道要求：**1.5—3 分钟**，**开头必须报姓名与学号**。
> 建议 1080P、浏览器全屏、隐藏书签栏，录前先跑一遍 `pnpm seed:demo` 保证数据完整。

---

## 录制前 3 分钟准备（清单）

- [ ] `pnpm dev` 已启动，浏览器打开 http://localhost:5173
- [ ] 关闭无关标签页、微信/QQ 弹窗、系统通知（Windows 专注助手开启）
- [ ] 麦克风可用（要现场演示一次实时语音识别，展示文字稿真的会有）
- [ ] `pnpm seed:demo` 已跑过 → 演示数据在（张明 88 / 李婷 68 / 王浩未练）
- [ ] 准备两个浏览器窗口：窗口 A = 学生端，窗口 B = 老师端（互不干扰，切换更快）
- [ ] 提前登录好：学生 `S2025011` / 老师 `T9001`，密码都是 `12345678`
- [ ] 录屏工具：Xbox Game Bar（`Win + G`）或 OBS，选区 1920×1080

## 分镜脚本

### 镜头 1 · 开场（0:00 — 0:12）

**画面**：浏览器停留在学生首页 `/`（模拟面试设置页）

**你要说**：
> 老师好，我是 XX 级 XX 专业的（**姓名**），学号（**学号**）。
> 我带来的作品叫「面试镜 · 学生表达训练平台」，面向专升本和高职学生的模拟面试训练。

**动作**：鼠标轻轻划过岗位方向输入框，不要点开始。

---

### 镜头 2 · 学生做一次模拟面试（0:12 — 1:00）

**画面**：同一页面

**动作**：
1. 岗位方向填 `软件开发工程师`
2. 勾选「我已了解上述说明」
3. 点「开始模拟面试」→ 允许摄像头麦克风
4. 页面加载模型（可等待，或提前预热过一次）
5. 进入第一题，**看着镜头说 10—15 秒**（说真话，让识别出字）
   建议说：「老师好，我叫张明，我做过一个二手交易平台，负责后端接口，用 Java 和 MySQL。」

**你要说**：
> 学生在浏览器里完成一次真实面试，摄像头画面和麦克风数据都在本机分析，
> 不打标记也能实时看到左侧的指标：眼神、语速、口头禅、姿态。

**动作**：鼠标指向右侧仪表盘（表情/眼神/语速）和底部提示条

**要点**：让画面里出现**识别出的文字**（这是「真的在识别」的证据）

---

### 镜头 3 · 报告页（1:00 — 1:40）

**画面**：点「完成面试」→ 报告页

**你要说**：
> 结束后立刻生成报告：五个维度的分数、逐题的结构分析、以及一条时间轴。
> 这里特别注意——语言表达这一项，如果没有识别到语音，我们不会给一个假的 50 分，
> 而是显示数据不足，综合分按其余维度重新计算。

**动作**：
1. 鼠标划过五维分数块
2. 滚动到「关键数据」（眼神 95%、语速、口头禅）
3. 点「导出成绩卡 PNG」→ 展示下载（**这是宣传物料之一**）

---

### 镜头 4 · 训练中心（1:40 — 2:05）

**画面**：`/drills`

**你要说**：
> 系统会根据报告里的薄弱项，自动推荐三个专项训练。这里一共五个训练项：
> 眼神锁定、语速控制、口头禅清除、姿态矫正、自我介绍。

**动作**：进入「眼神锁定」→ 开始（画面出现摄像头 + 实时进度），**不要真的练完**，3 秒后返回

---

### 镜头 5 · 老师端看板（2:05 — 2:40）

**画面**：切到窗口 B，`/teacher/board`（老师已登录）

**你要说**：
> 老师这边，一个页面看清一个班：谁练了几次、最近多少分、哪一维全班都弱。
> 王浩一次都没练，这里会直接标成「未练习」预警。

**动作**：
1. 鼠标指向 张明 88 / 李婷 68 / 王浩「未练习」
2. 点「导出成绩单 CSV」（展示下载）
3. 点张明 → 学生详情页（报告列表 + 训练明细 + 薄弱项建议）
4. 回到班级管理页，快速展示「批量导入 + 每个学生随机初始密码清单」

---

### 镜头 6 · 收尾（2:40 — 2:50）

**画面**：回到老师看板或首页

**你要说**：
> 音视频全程不出本机，服务器只收每秒的指标摘要，老师看不到任何画面和录音。
> 这是训练工具，不是评判工具——我们只给可执行的动作，不给录用判断。
> 作品基于 MIT 开源项目二次开发，源码已开源。谢谢老师。

## 录制注意

| 事项 | 说明 |
|---|---|
| 语速 | 比平时慢 10%，每句之间停半秒，方便后期加字幕 |
| 鼠标 | 移动要慢、要停在目标上 1 秒；避免乱晃 |
| 录 2—3 遍 | 第一遍熟悉流程，第二/三遍选最顺的 |
| 时长控制 | 超过 3 分钟会被截断，宁短不长；每段可卡掉等待时间（模型加载可用剪辑加速） |
| 音量 | 用耳机麦或手机录音后期对齐，避免键盘声 |
| 输出 | `mp4`，命名 `赛道二-姓名-学号-面试镜演示.mp4` |
